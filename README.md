# Regal Chauffeuring Website

A static chauffeur booking website with an instant fare calculator.

## Features

- Premium landing page for a chauffeur service.
- Booking form that asks for full name, email, phone number, passengers, date, time, pickup place, destination, mileage, and special requests.
- Automatic quote calculator using a fixed rate of **£2 per mile** plus a **£25 booking fee**.
- Payment method selector with card fields shown only when card payment is selected.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
